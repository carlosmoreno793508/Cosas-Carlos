# ICP y cuentas objetivo — Vertical Electrónica

> Perfil de cliente ideal (para el piloto Astute) y lista semilla de cuentas objetivo. Las listas de contactos se enriquecen con ZoomInfo/Apollo/Wiza + el estudio Astute.

## ICP — a quién le vendemos oportunidades (lado proveedor)

**Cliente que paga (fase actual):** distribuidores de componentes electrónicos y EMS que necesitan abrir cuentas.
- Perfil: Astute, TTI, Arrow, Avnet, Future, Mouser, DigiKey y similares.
- Dolor: abrir cuentas nuevas, llegar a compradores difíciles de alcanzar.

## ICP — a quién prospectamos PARA el cliente (lado comprador = cuentas objetivo)

**Empresas objetivo (demanda):** OEMs y EMS con plantas en MX/US que compran componentes.

| Criterio | Valor |
|---|---|
| **Industria** | Electrónica de consumo, línea blanca, automotriz, industrial, EMS |
| **Geografía** | México (Bajío, Norte, Occidente) + Sur de EUA |
| **Tamaño** | 200+ empleados / planta de manufactura |
| **Señal de compra** | Expansión, nueva planta, nearshoring, EOL, allocation |

### Roles a contactar (buyer personas)
- Buyer / Purchasing Agent
- Commodity Manager
- Procurement Manager / Director
- Supply Chain Director
- Plant Manager / Materials Manager

## Cómo enriquecer (siguiente paso operativo)

Con las herramientas conectadas puedo:
1. **ZoomInfo / Apollo:** buscar contactos por empresa + rol (Commodity Manager, Procurement) en las cuentas de arriba.
2. **Wiza:** enriquecer con correos verificados.
3. Cruzar con el **estudio Astute** para priorizar por commodity y oportunidad real.

> ⚠️ Uso responsable: estas herramientas son para investigación B2B legítima. Nada de scraping masivo; extraemos por cuenta/rol para prospección con base legítima, respetando sus términos y la ley (CAN-SPAM / privacidad).

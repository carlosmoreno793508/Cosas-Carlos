# Protección de propiedad intelectual — GrowProkure

> Orientación práctica (2026-07-16). **No es asesoría legal.** Para presentar trámites, usar un agente de propiedad industrial / abogado de PI. Costos aproximados, verificar con IMPI/INDAUTOR/USPTO.

## Idea central
Lo que construimos (newsletter, base de datos, modelo de negocio, marketplace, servicio de IA) **casi no es patentable** — y no lo necesita. Los métodos de negocio y el software "como tal" están **excluidos de patente en México**. Lo que protege este negocio es **MARCA + SECRETO INDUSTRIAL + DERECHOS DE AUTOR**, no patentes.

| Qué proteger | Instrumento | Costo aprox | Prioridad |
|---|---|---|---|
| Nombre "GrowProkure" + logo | Marca / Trademark (IMPI) | ~$3,000–4,000 MXN por clase | 🔴 YA (urgente) |
| Base de datos + método + fuentes | Secreto industrial (NDA + confidencialidad) | ~gratis | 🔴 Alta |
| Newsletter, código, textos | Derechos de autor (INDAUTOR) + Git | ~$250 MXN/obra | 🟡 Media |
| Invento técnico novedoso | Patente | US$3,000–15,000+ | ⚪ Probablemente no aplica |

## 1. Marca "GrowProkure" — IMPI (lo más importante y urgente)
- **Urgencia:** México es **first-to-file**. Registrar ANTES de salir grande en LinkedIn (si no, alguien puede registrarla primero).
- **Dónde:** IMPI, en línea (marcanet / portal IMPI).
- **Costo:** ~$3,000–4,000 MXN por clase (~US$180–230). Búsqueda fonética opcional ~$1,200 MXN.
- **Clases (Niza) recomendadas:**
  - **Clase 35** — datos/negocio, publicidad, bases de datos comerciales (la principal).
  - **Clase 42** — software/SaaS, tecnología (si vendes plataforma/IA).
  - Opcional: Clase 16/41 (publicaciones/newsletter).
  - Arranque: **35 + 42** (~$6,000–8,000 MXN total).
- **Proceso:** búsqueda fonética → solicitud → examen → publicación → registro. ~4–8 meses. Vigencia 10 años, renovable.
- **EE.UU. (después):** USPTO ~US$250–350/clase + abogado obligatorio para extranjeros.

## 2. Secreto industrial — el verdadero foso (gratis)
La base de datos, el motor de señales, el stack de fuentes y el método valen más como **secreto** que como patente (patentar obliga a publicarlos).
- **NDA** con quien vea los datos (empleados, socios, clientes).
- Marcar "Confidencial – GrowProkure".
- Control de acceso (repo privado; contraseñas fuera de git ✓).
- Costo: ~gratis (formato NDA estándar).

## 3. Derechos de autor — INDAUTOR (respaldo barato)
- Copyright **automático** al crear; registrar da **prueba con fecha**.
- **Costo:** ~$250 MXN por obra. Registrar: newsletter (publicación periódica), código, docs clave.
- **Git ya es prueba de autoría con timestamp** (registro público de facto de fechas de creación).

## 4. Patente — por qué (casi seguro) NO
- Métodos de negocio + software "como tal" no patentables en México.
- US software-patent: caro (US$10–20k+), lento (2–4 años), difícil (Alice/§101).
- Solo si aparece un invento técnico muy específico y novedoso (hoy no existe).

## Plan recomendado (orden)
1. **Búsqueda fonética** de "GrowProkure" en IMPI (que no exista igual/parecida).
2. **Registrar marca** GrowProkure clases 35 + 42 en IMPI.
3. **Formato NDA** listo para socios/empleados/clientes; marcar datos como confidenciales.
4. (Opcional) Registrar newsletter + código clave en INDAUTOR.
5. Mantener el **repo Git** como bitácora de autoría con fechas.
6. Patente: descartada por ahora.

> El foso real de GrowProkure no es una patente: es **la data (secreto) + la marca + el efecto de red + la ejecución**. Proteger eso primero.

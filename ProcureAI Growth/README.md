# ProcureAI Growth

Proyecto para diseñar una solución **única** que ayude a **clientes (compradores)** y **proveedores** a conectarse y operar mejor, apoyada en IA.

El objetivo de esta carpeta es tomar los conceptos de negocio propuestos por **ChatGPT** y **Gemini**, fusionarlos, y construir a partir de ahí una sola propuesta diferenciada.

## Estructura de la carpeta

| Carpeta | Contenido |
|---|---|
| `01-Concepto-Negocio/` | La propuesta fusionada y unificada del negocio. |
| `01-Concepto-Negocio/fuentes/` | Los documentos originales de ChatGPT y Gemini (sin modificar). |
| `02-Investigacion/` | Investigación de mercado, competencia, tamaño de oportunidad. |
| `03-Producto/` | Definición de producto, features, MVP, arquitectura. |
| `04-GoToMarket/` | Estrategia comercial, precios, canales, adquisición. |
| `05-Recursos/` | Material de apoyo, referencias, notas sueltas. |

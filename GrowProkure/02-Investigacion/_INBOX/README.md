# 📥 _INBOX — Bandeja de entrada de datos (la vigila Prokure)

Suelta aquí cualquier **Excel con contactos nuevos** y Prokure lo procesa:
lee → normaliza → **deduplica contra la Base Maestra** → integra solo lo nuevo → reporte.

## Cómo alimentar la bandeja
1. En la sesión donde generaste los datos, **exporta/descarga el Excel**.
2. **Súbelo aquí** (a esta carpeta en GitHub web) o **adjúntalo en el chat** de esta sesión.
3. Dime *"Prokure, audita el INBOX"* y lo integro.

> No puedo jalar de enlaces de sesión de Claude (dan 403 y no son archivos).
> El camino que funciona: el Excel llega como archivo (subido aquí o adjunto).

- **Confianza:** "Alta" = visto en su sitio propio; "Baja" = solo del DENUE.

## ⚠️ Cumplimiento (leer antes de usar)
- El **DENUE es dato público oficial** (INEGI) → ok para investigar y segmentar.
- **PERO** contactar en frío a consultorios por WhatsApp/correo cae bajo la **LFPDPPP** (protección de datos MX) y, en WhatsApp, bajo el **riesgo de baneo** por mensajería masiva no solicitada.
- Reglas de oro (mismas que GrowProkure, ver `../../REGLAS.md`):
  - **R3 — no inventar:** los links `wa.me` NO confirman WhatsApp activo; verificar antes de prometer.
  - **R10 — nada de blasting:** nada de envíos masivos en frío. Preferir **inbound** (que ellos escriban) o outbound **opt-in** con plantillas aprobadas.
  - Si se usa con Vocero/WhatsApp Cloud API → **API oficial**, plantillas aprobadas, y respetar ventana de 24h.

## Cómo conecta con lo demás
- Este directorio puede ser el **combustible de prospección** para un piloto de **Vocero CRM** (WhatsApp) enfocado al sector salud — pero empezando **inbound/opt-in**, no masivo.
- Es una **vertical distinta** a Electrónica/Plásticos; por eso vive aquí como estudio y **NO se fusiona** con `05-Recursos/Base_Maestra_GrowProkure.xlsx`.
